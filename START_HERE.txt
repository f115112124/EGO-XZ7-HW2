EGO-XZ7 HW2：另一台電腦開始操作

前提：已安裝 Vivado 2018.3、Xilinx SDK 2018.3 與 USB Cable Drivers。

1. 將 ZIP 解壓到 C:\，確認存在 C:\soc_hw2\export\design_1_wrapper.hdf。
2. 接上 EGO-XZ7 的電源與 USB-JTAG/UART 線，開啟電源。
3. 開啟操作 PPT，依主線建立新的 SDK workspace：C:\soc_hw2\sdk。
4. 匯入 HDF、建立 hw2_demo 並匯入 main.c，依 PPT 編譯、Program FPGA、執行 ARM 程式。

C 原始碼：C:\soc_hw2\firmware\hw2_demo\main.c
預編譯程式：C:\soc_hw2\demo\hw2_demo.elf
預編譯 FPGA：C:\soc_hw2\demo\design_1_wrapper.bit
預編譯 PS 初始化：C:\soc_hw2\demo\ps7_init.tcl
硬體平台：C:\soc_hw2\export\design_1_wrapper.hdf
完整說明：C:\soc_hw2\README_另一台操作.md

成功時 LED 每 0.5 秒加 1。按 A10 貼紙左方十字中央 S6，LED 熄滅約 2 秒後從 1 計數。
UART：115200、8N1、無流量控制。另一台 COM 編號要重新確認。
只載入 bit 不會執行 C 程式。斷電後要重新下載。
